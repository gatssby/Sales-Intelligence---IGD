# Domain docs

Este repositório usa um único contexto de domínio.

## Antes de explorar

- Leia `CONTEXT.md` quando existir e use seus termos canônicos.
- Leia os ADRs relevantes em `docs/decisions/`.
- Leia `README.md`, `docs/architecture.md` e `docs/data-model.md` antes de mudanças estruturais.

## Convenção preservada

- O glossário do domínio fica em `CONTEXT.md` na raiz.
- Decisões arquiteturais continuam em `docs/decisions/`; não mova ADRs para outra pasta apenas para seguir uma convenção externa.
- Se uma proposta contradizer um ADR existente, explicite o conflito antes de implementar.
- Crie termos e ADRs somente quando uma decisão real os justificar.
