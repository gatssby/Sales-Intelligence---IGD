# Issue tracker: GitHub

Issues e specs deste repositório vivem nas GitHub Issues de `gatssby/Sales-Intelligence---IGD`. Use `gh` a partir deste clone para ler, criar, comentar, rotular e fechar issues.

## Convenções

- Preserve os labels existentes; não crie nem renomeie labels apenas para adequar uma skill.
- Pull Requests não são uma fila de triagem de produto.
- Um número como `#42` pode identificar issue ou PR; resolva o tipo antes de alterar seu estado.
- Quando uma skill disser para publicar no issue tracker, crie uma GitHub Issue, salvo instrução explícita em contrário.
